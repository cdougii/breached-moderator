# Breached - Night Phase Moderation App

A web-based night phase moderation app for the Breached card game. This app helps moderators guide players through the night phase with clear on-screen instructions.

## Features

- **Role Selection**: Select which roles are involved in the game
- **Night Phase Flow**: Guides through role actions in designated order
- **Team Toggle**: Choose which teams (Human/Alien) act during each night phase
- **Day Phase**: "Find Your Friends" screen between night phases
- **Continuous Loop**: Night and day phases loop until "New Game" is selected
- **Special Rules**: Both Captains always act regardless of team selection

## Roles

1. Bodyguard (Order 1)
2. Captain (Order 2) - Always acts regardless of team selection
3. Scientist (Order 3)
4. Technician (Order 4)
5. Saboteur (Order 5)

## How to Use

1. Open `index.html` in a web browser
2. Select which roles are in the game
3. Click "Start Night Phase"
4. Navigate through each role's turn
5. After night phase, use day phase to select which teams act next
6. Click "Start Night Phase" to continue the loop
7. Click "New Game" to return to role selection
